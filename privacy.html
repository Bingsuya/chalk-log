개인정보처리방침

시행일: 2026년 11월 9일

Chalk Log(이하 "앱")는 운동 기록을 남기는 개인 프로젝트예요. 기록을 저장하는 데 꼭 필요한 정보만 받고, 다른 곳에 팔거나 넘기지 않아요.

1. 어떤 정보를 받나요

  • 구글 로그인 정보: 이메일 주소, 이름, 계정 식별값. 로그인할 때 구글이 앱에 전달해요.
  • 직접 입력한 운동 기록: 운동한 날짜와 종목, 운동 시간, 컨디션, 메모, 동작별 중량 기록.

광고용 추적, 위치 정보, 연락처, 사진은 받지 않아요.

2. 왜 쓰나요

  • 로그인한 사람을 구분하고, 그 사람의 기록만 보여주기 위해
  • 여러 기기에서 같은 기록을 볼 수 있게 저장하기 위해

3. 어디에 보관하나요

기록은 데이터베이스 서비스 Supabase에 보관돼요. 각 사용자는 자기 기록만 읽고 쓸 수 있도록 데이터베이스 규칙으로 막혀 있어요. 앱 관리자는 서비스 운영과 문제 해결을 위해 관리 화면에서 저장된 기록과 가입한 이메일을 볼 수 있지만, 그 밖의 목적으로 보거나 쓰지 않아요. 로그인 없이 쓰는 경우 기록은 사용 중인 기기의 브라우저에만 저장되고 서버로 보내지 않아요.

4. 다른 곳에 넘기나요

넘기지 않아요. 다만 앱을 운영하기 위해 아래 서비스를 사용해요.

  • Google — 로그인
  • Supabase — 로그인 처리와 기록 저장
  • GitHub Pages — 앱 화면 제공

5. 언제까지 보관하고, 어떻게 지우나요

계정을 쓰는 동안 보관해요. 앱 맨 아래 백업 · 기록 옮기기에서 계정 기록 모두 삭제를 누르면 서버에 저장된 내 운동 기록이 바로 지워져요. 로그인 정보까지 완전히 지우고 싶으면 아래 연락처로 요청해 주세요. 확인 후 지체 없이 삭제해요.

6. 문의

개인정보 관련 문의는 구글 로그인 화면에 표시되는 개발자 연락처 이메일로 보내주세요.

이 방침이 바뀌면 이 페이지에 바뀐 날짜와 함께 알려드려요.
