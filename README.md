# Chalk Log

운동한 날의 종목을 달력에 기록하고, 크로스핏 동작별 1RM(PR)과 추이를 관리하는 웹앱입니다.
홈 화면에 추가하면 앱처럼 전체 화면으로 열리고, 오프라인에서도 동작합니다.

- 구글 로그인 시 기록이 계정(Supabase)에 저장되어 어느 기기에서나 같은 기록을 봅니다.
- 로그인 없이 쓰면 기록은 그 기기에만 저장되고, 나중에 로그인하면 자동으로 계정으로 옮겨집니다.
- 하단 "백업 · 기록 옮기기"로 기록을 글자로 내보내고 불러올 수 있습니다.

## 파일

- `index.html` – 앱 전체 (화면, 기록, 그래프, 로그인·동기화)
- `config.js` – Supabase 주소와 공개(anon) 키. 비어 있으면 로그인 없이 기기 저장 모드로 동작
- `supabase/schema.sql` – 데이터베이스 표와 접근 규칙 (각자 자기 기록만 읽고 쓰기)
- `SETUP.md` – 로그인·계정 저장 설정 안내
- `manifest.webmanifest`, `icons/`, `sw.js` – 홈 화면 앱 설정과 오프라인 지원
