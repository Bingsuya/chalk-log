      기록은 어디에 저장돼요?

      로그인하면 계정에 저장돼서 휴대폰·PC 어디서든 같은 기록이 보여요. 로그인 없이 쓰면 지금 쓰는 기기에만 저장돼요.

      폰을 바꾸면 기록이 사라지나요?

      로그인해서 쓰고 있다면 새 폰에서 같은 구글 계정으로 로그인하면 그대로 있어요. 로그인 없이 썼다면 맨 아래 '백업 · 기록 옮기기'로 옮겨 주세요.

      인터넷이 끊겨도 기록할 수 있어요?

      네. 기록은 바로 화면에 남고, 인터넷이 연결되면 자동으로 계정에 저장돼요.

      내 기록을 지우고 싶어요.

      로그인한 상태에서 맨 아래 '백업 · 기록 옮기기' → '계정 기록 모두 삭제'를 누르면 돼요.

      의견 보내기

      불편한 점, 있었으면 하는 기능, 칭찬 다 좋아요. 보내주신 의견은 관리자만 읽어요.

      고마워요! 잘 받았어요 💌

      보내주신 의견은 꼼꼼히 읽어볼게요.
